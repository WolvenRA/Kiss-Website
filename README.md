# DuewyKiss.com

Static website for the Kiss / Duewy computer architecture project.

This repository is published with GitHub Pages from the `Main` branch and the repository root.
The custom domain is configured by `CNAME` as `DuewyKiss.com`.

## Contents

- `index.html` — website landing page
- `css/`, `js/`, `images/` — static assets
- `downloads/` — public manuals, references, simulator packages, and VS Code extensions

## Publishing note

The source website currently lives in the main Kiss workspace under `projects/Kiss/website/` and is published as a clean static copy to `WolvenRA/Kiss-Website`.
